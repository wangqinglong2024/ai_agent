# 04 · G04 · 文档目录规划（AI 输出落盘约定）

> 本框架所有 AI 产出物统一落到项目根目录 `/docs` 下。本文件给出完整目录树与每个文件的命名约定，AI 必须严格遵守。
>
> 命名总则：
> - F 阶段子目录带 `F0[1-4]-` 前缀（项目级，全局唯一）。
> - C 阶段子目录带 `C0[1-8]-` 前缀，下分 `<feature>/`（每个 feature 一份）。
> - 与 `/prompt/` 下提示词文件的阶段编号一一对应。

---

## 二、命名约定

| 对象 | 规则 | 示例 |
|------|------|------|
| feature-id | 全小写，短横分隔 | `order-mgmt` |
| endpoint-id | `<method>-<resource>` | `get-orders`、`post-orders` |
| page-id | `P-<feature>-<seq3>` | `P-order-012` |
| scope | `public` / `app` / `admin` | `app-home.html` |
| 文件名小写 + 短横 | 不要空格、不要中文 | `01-tech-stack.md` |
| 索引 `00-index.md` | 每个有多文件的子目录都要有 | — |
| 待确认 `99-open-questions.md` | 每个子目录都要有 | — |
| 用户输入存档 | `_input/` 子目录 | `_input/draft.md` |
| 全局共享文件 | `_global` / `_global-*.md` 前缀 | `_global-routes.md` |

## 三、AI 落盘行为约束

每次 AI 输出最终文件时必须：

1. **声明落盘路径**：在文件头第一行写：
   ```
   <!-- TARGET-PATH: docs/C06-data/order-mgmt/01-tables.md -->
   ```
2. **多文件输出**：若一次产出多个文件，逐个用 `<!-- TARGET-PATH: ... -->` 标注；用户按标注切分保存。
3. **拆分原则**：单文件 ≤ 1200 行；超出按本规划的子目录结构拆。
4. **更新索引**：拆分后必须同时更新对应 `00-index.md`，列出所有子文件 + 一句话职责。
5. **更新全局索引**：C 阶段产物必须同步更新对应的全局索引（如 C02 更新 `_global-routes.md`、C05 更新 `_global-index.md`）。
6. **移交问题**：未决问题写入对应子目录的 `99-open-questions.md`，不是塞在正文。

## 四、变更与冻结

- **单文件冻结**：在文件头 `冻结状态` 改为 `已冻结`。
- **子目录冻结**：在该子目录 `00-index.md` 顶部写 `冻结状态: 已冻结 · YYYY-MM-DD · 签字: <name>`。
- **变更记录**：所有冻结/解冻写入 `docs/S00-meta/changelog.md`。
- **F 层变更广播**：F01~F04 任一文件变更，须在 `changelog.md` 列出受影响的所有已开工 feature，并触发它们的 C08 V 重跑。
