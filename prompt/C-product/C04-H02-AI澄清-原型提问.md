# 33B · H02 AI 澄清：原型提问模板

> **阶段**：H HTML 原型
> **谁来写**：AI（拿到首版原型触发或迭代反馈后）
> **落盘**：`docs/C04-prototype/<feature-id>/_input/H-questions-round<N>.md`
> **下一步**：用户答完后，AI 按 `C04-H03` 出新一版原型 + changelog。

---

## 何时触发本模板

1. **首版原型生成前**：用户已备齐 N 全部 + B03 + B04 + 本 feature C02 IA，但 AI 在生成前发现仍有歧义/缺失（页面缺 IA 钩、token 不存在、交互断点未定义、跨页一致性不明、空/错状态未约定等），必须先按本模板提问，禁止臆测填充。
2. **迭代反馈处理前**（C04-H01 已写完一份 feedback-round<N>）：反馈内部矛盾、范围不清、违反 B03/B04 token、可能波及未列页面时，AI 先按本模板提问。
3. **如果反馈完全自解释、零歧义**：可跳过本模板，直接进入 `C04-H03`，但要在 changelog.md 标注"H02-skipped"。

---

## 输出位置规则

- 首版：`H-questions-round0.md`
- 第 N 轮反馈：`H-questions-round<N>.md`，`<N>` 与 `feedback-round<N>.md` 对齐。

## 必答提问清单（AI 自检后只问真有歧义的）

### A. 与上游一致性
1. N 规范里的 `page-id` / `Block-ID` 与本轮反馈引用的是否一一对应？缺哪些？
2. C02 IA `04-pages.md` 与本次要新增/改动的页面是否一致？是否需同步回写 04-pages.md（页面增删属于 C02 范畴）？
3. C02 IA `03-state-machines.md` 涉及的页面在原型里是否已表达不同状态下的差异？
4. B03 体验原则是否被违反（如焦点态、动效时长、空状态文案语气）？
5. B04 设计系统：本次需要的 token / 组件是否已存在？若不存在，是补 token 还是绕开？

### B. 原型实现边界
6. 数据来源：用静态 mock？还是 `_mock/` 目录的某个 JSON？字段命名归谁？
7. 交互真实度：表单只做前端校验，还是要模拟提交 loading + toast？
8. 原型内跳转：以 page-id 命名 HTML 文件（如 `<page-id>.html`）作锚，URL 路径属于 D02 L 范畴，本阶段不假设。
9. 可访问性：键盘可达、`aria-*`、`prefers-reduced-motion` 是否本轮纳入？

### C. 反馈条目歧义（仅迭代轮次需要）
10. F-<n>「<引用原文>」中的 `期望` 与现有 N 规范第 X 节是否冲突？以哪条为准？
11. 全局诉求「<引用原文>」会影响哪些未在反馈里点名的页面？是否一并改？
12. 反馈优先级「应改/可改」在本轮是否纳入？还是只做"必改"？

### D. 范围与产出
13. 本轮原型涉及的 `page-id` 完整清单是？（AI 列出，请用户勾选）
14. 是否需要更新 `00-index.md` 与 `changelog.md`？是否需要写 README 给评审？
