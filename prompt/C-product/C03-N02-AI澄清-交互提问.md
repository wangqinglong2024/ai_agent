## AI 必须遵守

1. **只读**：N 用户输入 + 本 feature C01-R 基线 + docs/B02-permissions/ + 本 feature C02-I + docs/B03-ux/ + docs/B04-design-system/ + `A00-01`、`A00-03`、`A00-04` + 本模板。
   > **严禁**：本阶段不允许读 docs/B01-architecture/、docs/D01-data/、docs/D02-api/（C 与 D 隔离；D 阶段还未运行）。
2. 第一轮回复必为本模板实例化。
3. 阻断级 ≤ 8、优化级 ≤ 15。
4. 任何与 B03 决策、B04 token 冲突的备选不得出现。

---

## 必盘点的 12 维

1. 用户单一目标是否明确（一页只服务 1-2 个核心目标）
2. 区块清单与权重（首屏优先级）
3. 操作清单（OP-ID）与期望服务端能力描述是否齐全（API-ID 留待 D02 L 反向映射）
4. 状态四件套（默认/加载/空/错误）
5. 角色差异（未登录、不同角色、自己 vs 他人、有权 vs 无权）
6. 表单交互（校验时机、错误展示、提交反馈、未保存提示）
7. 关键场景（SC-X）覆盖度（≥ 5 条且含异常）
8. 移动端形态变化
9. 键盘/快捷键/无障碍要求
10. 性能预算（首屏元素、骨架屏、懒加载）
11. 文案语气（与 docs/B03-ux/04-voice-tone.md 一致）
12. SEO（公开页适用）
